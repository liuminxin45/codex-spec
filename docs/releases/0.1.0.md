# Codex Spec 0.1.0

以 `codex-spec` 为项目、发行包和命令名称，原生 Skill 为 `$codex-spec`。这是替代旧 Spec Kit 的新起点，不保留旧命令、数据结构和阶段引擎兼容层。

提供一个总 Skill、七份按需工程指南、独立 Spec 文档和项目知识索引。重点改善产品目标、UI 一致性、状态与接口判断、可验证切片、失败诊断和真实行为验证。

删除固定阶段、Hook、工作流状态机、分支创建与同步、会话所有权和脏工作区限制。多个 Spec、多个 Codex 会话可直接共用当前工作区。提交通过 `Spec:`、`Spec-Docs:` 关联文档。

CLI 使用 Python 3.11+ 标准库，无运行依赖。提供 wheel、源码包和 SHA-256 校验文件。源码 CI 覆盖 Windows/Linux、Python 3.11/3.13、安装包隔离安装与三个源码校验脚本。

包括四类行为评估任务与可执行反例；工具测试结果不代表已完成真实模型对照实验。UI 体验与人的反馈继续按实际证据报告。

已有项目请参照 [安装与干净升级](../agent-setup.md) 审查旧入口，保留业务文档。原始 MIT 版权声明及历史提交继续保留。
