# Codex Spec 0.1.1

本版本补齐需求澄清、UI 参照、真实宿主验收和源码修改约束。
CLI 与项目配置格式兼容 0.1.0，无新增运行依赖。

## 工程指导

- 主动澄清影响目标、交互、兼容性或验收的未知项。默认值和沉默不代表用户确认。
- UI 外观修改前，至少找到并实际查看一种可靠视觉参照：现有截图、Qt 原稿或 UI 设计稿。
- 对支持 CDP 的宿主，连接并确认真实目标和加载版本，截图检查视觉效果，操作后核对结果。原生 UI 使用适用工具。
- 持久修复落在维护源码或生成源中，再通过项目流程更新产物。
- 重要变更尽早确认验证入口，并用可能误判成功的反例检查验收是否有效。
- 明确切片完成范围、截图实际状态和续接记录中的最新结论。

独立的 codex-spec-review 维护技能提供开发后主动复核入口，不随项目初始化安装。
本版本不增加阶段引擎、执行收据、会话锁或审批流程。

## 安装与更新

安装发布 wheel，或使用 GitHub 的 `v0.1.1` 固定版本。
已有项目先检查受管理文件的差异，再运行 `codex-spec init --replace` 和安装检查。
更新保留项目知识、Spec 和 AGENTS.md 受管理区块之外的内容。
参见[安装与升级](../agent-setup.md)。

源码检查和安装包冒烟验证工具及分发行为，不证明模型成功率或产品质量提升。
