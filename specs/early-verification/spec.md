## 决策与依据

此前指南已要求真实入口、反例和证据边界。
本次补充确认验证能力的时机，并替换原验收段落的表述。

验证入口缺失属于待判断的能力限制，不自动阻塞独立工作。

工程指导修改保持索引、模板、CLI 命令和依赖不变。
不增加阶段、执行器、收据、审批或强制新增测试。

默认入口说明主动澄清和源码修改，详细 UI 约束放在按需指南中。
视觉参照至少包含一种已查看的截图、Qt 原稿或 UI 设计稿。
CDP 用于支持该协议的宿主；原生 UI 使用适用工具。
验收必须核对真实目标和加载版本，观察操作后的实际结果。
缺失运行能力时保留未验证项；检查入库生成文件遵循项目已有规则。
